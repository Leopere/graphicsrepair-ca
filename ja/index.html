01 / 症状

確認する問題

お引き受けしたカードの故障を診断してから、修理の見積りをお伝えします。

映像なし・電源なし

安全にテストできることを確認してから、電源回路の短絡、電圧調整回路（VRM）の損傷、ファームウェアの不具合、コネクターの損傷、部品の故障を調べます。

画面の乱れやクラッシュ

画面の乱れ、ドライバーのクラッシュ、負荷がかかったときの不具合には、カードのメモリ（VRAM）、GPU、電源回路、ファームウェア、冷却、またはパソコン自体が関係する場合があります。

過熱や物理的な損傷

部品が入手でき、テストできる場合は、ファン、熱伝導材、腐食、基板配線、HDMIやDisplayPortの損傷を確認できます。

02 / 対応するグラフィックボード修理

対応するグラフィックボード修理

対応可能なNVIDIA GeForceとAMD Radeonのデスクトップ用カードを扱います。一部のワークステーション用モデルも対象です。Intelのグラフィックボードは通常受け付けていません。受付できるかは、正確なモデル、状態、新品や部品取り用カードの部品の入手状況、安全にテストできるかによって決まります。

  • 電気的な故障や電源の問題の特定
  • マイクロはんだ付け、コネクターや基板配線の修理
  • 診断で必要と判断した場合の電圧調整回路（VRM）、メモリ、コンデンサーや抵抗などの受動部品の交換
  • 診断結果と修理費用から妥当と判断した場合のBGAチップのはんだ作業
  • カードの状態が許す範囲での清掃、冷却系の整備、動作確認や負荷テスト

カードを送る前に

  • 症状だけでは、GPUコアやメモリチップの故障とは断定できません。
  • リボールや部品交換を含め、修理を試みても直ることは保証できません。
  • ノートパソコンの基板にはんだ付けされたGPU、内蔵グラフィックス、非対応カードは、別途書面での受付承認が必要です。
  • 履歴と正確なモデルを確認する前に、カードをオーブンに入れたり、ヒートガンを使ったり、発送したりしないでください。

03 / 流れ

修理の流れ

  1. 1

    カードについてお知らせください

    メーカー、正確なモデル、症状、修理やマイニングの履歴をすべてお知らせください。お引き受けできるか判断します。

  2. 2

    返事をお待ちください

    受付可能な場合は、持ち込みまたは郵送の方法をご案内します。当店が受付を承諾するまでは発送しないでください。

  3. 3

    診断と見積り

    カードが届いたら診断し、見積りをお伝えします。お客様の承認なしに修理を始めることはありません。

  4. 4

    修理・テスト・返送

    見積りの承認後、合意した修理を行い、カードの状態が許す範囲でテストして返送を手配します。

04 / GPU Certification

GPU Certification

GPU Certificationでは、中古のデスクトップ用グラフィックボードを、販売時の掲載内容やそのモデルに必要な部品と照合します。料金は50カナダドル＋税です。受付済みのカードを調べ、識別情報、モデル、メモリ、チップ、基板、クーラー、その他の必要な部品を記録します。これにより、チップの欠落、交換、改変など、誤解を招くネット販売で見られる相違が分かる場合があります。店内のテスト用パソコンで起動も試みます。報告するのは確認できた事実だけです。メーカーの基準への適合、所有権、販売者の意図を証明したり、詐欺の法的な判断をしたりするものではありません。

  • 搭載されているチップや必要な部品を記録し、そのモデルに必要な部品と比較します
  • カードが起動した場合は、実施した検査と確認した結果を記載したテスト報告書をお渡しします
  • 修理診断ではなく、真正性や性能の保証、製品保証、隠れた故障がないことの保証もありません
  • 送料、修理、部品は別料金です。確認作業の開始後は返金できません
50カナダドル＋税依頼内容の確認は無料です。カードの診断は別の作業です。GPU Certification
